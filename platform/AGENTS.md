# 한국어 제품 문구

사용자는 추상적인 구호, 수사적 질문, 대화체 제목을 원하지 않는다.

- 제목은 분석 대상·지표·기능을 직접 명명한다. 예: `기업 전환계획 비교`, `입력 데이터·출처`, `비용·위험 지표 정의`.
- `가정을 바꾸고, 위험을 확인하기`, `숫자가 어디서 오는지`, `같은 목표, 다른 결과`, `함께 읽기`, `시장 가격에서 기업의 선택으로` 같은 제목을 쓰지 않는다.
- 버튼은 실행 동작이나 목적지를 표시한다. 예: `재계산`, `전환계획 비교`, `연간 원장 CSV`.
- 설명은 짧고 구체적인 문장으로 쓴다. 제목을 간결하게 만들기 위해 필요한 정의·단위·조건·한계를 삭제하지 않는다.
- 기업 후보의 저장 결과와 공정 참조 실험의 실시간 재계산을 구분한다. 실제 제공하지 않는 기능을 암시하지 않는다.
- 문구 수정만으로 수치, 계산식, 원문 인용, 회계·공정 경계를 변경하지 않는다.
