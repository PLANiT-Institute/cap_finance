# CAP-KJ complex-model v1 snapshot

**Snapshot date:** 2026-08-05  
**Status:** archived; retained for audit and possible later reuse

This directory preserves the pre-simplification analytical assets before the three-step investor model became the primary output. No source or result was deleted.

Included:

- all generated `outputs/` tables, figures, reports and diagnostics available at the snapshot;
- the emissions-pathway, cost-gap, support-experiment and capital-flow calculation modules most directly responsible for those outputs;
- the pathway, annual-cost and support assumption tables;
- ADR-001, which records the earlier capital-flow and priced-risk boundary.

The archived outputs remain reproducible screening work, but they are no longer the preferred public-facing narrative because the number of layers and figures obscured the central conclusion. The live project now uses three headline steps:

1. GCAM-aligned capital envelope (`G-CAP`) allocated to companies and compared with route-identified capital;
2. a level-gap rate and a transition-premium proxy on that capital envelope;
3. level-only, premium-only and combined modelled emissions effects centred on representative technologies.

Files in this archive should not be edited in place. Corrections belong in the live pipeline, with a new snapshot if necessary.
