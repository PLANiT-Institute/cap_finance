# 전환 시점 비교 사용 안내

통합 파일 v5의 `Timing`에서 전환 시점별 배출 자격과 비용을 비교한다. 기존 `Control`과 `NCC cash`는 각각의 계산 범위를 유지한다. 서로 다른 통화·가격연도·공정 경계의 결과를 합산하지 않는다.

v6부터는 세 분석을 한 번에 갱신하는 [전체 재계산](ALL_MODELS_CONTROL_KO.md)도 지원한다. 아래의 Timing 전용 갱신과 달리 모든 입력을 먼저 검사하고 세 분석 검증 후 새 파일을 발행한다.

## 사용 순서

1. `Timing`의 노란 셀 B14:B27에서 가정을 바꾸고 저장한다.
2. 저장한 파일로 **Timing 재계산**을 요청한다. 입력이 바뀐 동안 이전 결과는 ‘재계산 필요’로 표시한다.
3. 새로 저장된 결과 파일에서 ‘최신 계산’, 후보별 ‘적격/불가’, 비용과 효율경계를 확인한다.

Excel 자체 수식은 저장된 가격 표본의 위험통계와 연간 비용을 다시 계산한다. 새 몬테카를로 표본·설비 일정은 프로젝트 계산기를 실행해야 바뀐다. 매크로나 외부 데이터 연결을 넣지 않았다. 이 갱신은 Timing의 세 시트만 다시 구성한다. 기존 다른 모형의 입력을 바꿨다면 그 모형도 별도로 재계산해야 한다.

## 바꿀 수 있는 조건

가격 시나리오, 경로 수, 시드, 월별 블록 길이, 위험 분위수, 2027·2050 전력계수, 공통 잔여배출, 누적예산 비율, 말기 상한 비율, 제약 종류, 할인율, 기존 설비 남은 수명, 교체비 배율의14개 항목이다. 빈칸이나 입력 셀의 수식은 받지 않는다. 명시적 숫자0은 허용 범위에서 유효하며 빈칸과 구별한다.

- **누적+말기:** 같은 전력·잔여배출 조건에서 기존 설비를 계속 가동할 때의 누적배출에 예산 비율을 곱한다. 말기 상한은2027년 기존 유지 배출량에 말기 비율을 곱한다. 두 제약을 모두 충족해야 한다.
- **연도별 선형:** 2027년 기준배출에서 지정한2050년 말기 상한까지 직선으로 잇고 매년 검사한다. 이 모드에서 누적예산 비율은 적격 여부를 결정하지 않는다. 현재 네 전환 후보는 초기 재래식 가동 때문에 기본 선형 상한을 모두 위반한다.

적격 후보가 없으면 비용을0으로 채우지 않고 ‘불가’로 표시한다. 이때 새 가격 표본도 만들지 않는다. 경계는 **평균 기대비용과 표본 ES**의 비지배 후보이며, TCaR도 함께 제공한다. 시드 하나의 선택 결과가 실제 미래의 최적성이나 정책 권고는 아니다.

## 고정된 참조 가정

매년 에틸렌92만t, 가동 시작2030/2035/2040/2045, 건설3년, 전기화 설비 수명20년, 기존 플랜트30년·보일러25년, 유효 증기회수1, 생산 차질0, 말기 잔존수입0을 유지한다. 미확인 기업 구매전력이나 계약조건을 대입하지 않는다. 전력·잔여배출은 CO2 경계이며 회사 전체 CO2e나 전과정 배출을 검증한 값이 아니다.

전력 기준가격100의 절반을 일본 LNG 비율·충격에 연동하고, 메탄40·나프타600을 각각 LNG·원유 비율·충격에 연동한다. EUR2019 실질가격으로 놓은 가정이며 실제 조달가격이나 환율 관측값이 아니다. 같은 나프타 물량은 총비용에 포함되지만 증분에서 상쇄된다. 탄소지출·노무·운전자본·세금·금융·기타 공동제품 매출 등은 제외한다. 전력 배출경로와 가격의 공동 균형은 식별하지 않았다.

공정은 `NCC reference`와 연결된 Tiggeloven 원문 패키지, 직접배출은 기존 검증 등록부, 가격 중심 경로는 `Scenario source`와 연결된 IEA2025 및 World Bank 공동 월별 충격을 사용한다. 계산기는 공유 원문 값·단위의 변경을 검사하고 실행 근거 해시를 보존한다. 원문 패키지를 바꾸려면 기술 사양과 배출계수를 함께 다시 검토해야 한다.

## 검증과 범위

기본5000경로 결과는 직전 전환 시점 실험을 재현했다. 시나리오·경로수103·분위수0.93·예산·할인율·수명·교체비를 바꾼 경우에는2045 후보도 적격이 되고 경계가 달라졌다. 잔여배출을 넣거나 연도별 선형 제약을 고르면 빈 적격 집합을 정확히 표시했다.14개 입력 변경과 원문1개 변경에서 이전 결과를 보류했고, 빈칸·범위 초과·수식 입력3건을 거부했다.

저장 파일의 연간 현금 수식, 원장 합계, 분위수와 경계 질량을 포함한 ES를 별도 계산으로 대조했다. 기존10개 시트의 값·수식·스타일 및 구조를 보존했다. Artifact Tool 재계산과 XLSX 재열기 검증을 수행했으며, Microsoft Excel 앱에서의 동작은 아직 직접 실행하지 않았다. 본문 v2.21은 별도 편집을 보존하고 이 도구 추가로 재생성하지 않았다.

개발 재현: `scripts/timing_workbook_control.py --input <입력.xlsx> --output <새출력.xlsx> --scratch <빈실행폴더>`를 프로젝트 Python으로 실행한다. 기존 파일을 덮어쓰지 않으며 입력을 복제·검증한 뒤 새 결과를 발행한다. 현재 데스크톱의 번들 Node 경로를 사용하므로 다른 환경 배포에는 런타임 경로 설정이 필요하다.
