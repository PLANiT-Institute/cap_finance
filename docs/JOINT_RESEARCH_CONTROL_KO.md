# 공동 가격·NCC 부분 비용 Excel 통제

최신 통합 파일 v4는 10개 시트의 두 모형을 함께 갱신한다. `Control`의15개 가정과 `NCC cash`의18개 가정을 각각 읽고 두 계산·저장 검증이 모두 성공한 뒤 새 파일을 만든다. 두 모형은 공정·통화연도·비용 범위가 다르므로 입력을 자동 통일하거나 결과를 합산하지 않는다. 신규 설비 가정은 [신규 설비 원장 사용법](NCC_CASH_CONTROL_KO.md)을 따른다. 기존 단일 모형 생성 명령은 역사적 사용법으로 아래에 남긴다.

```bash
.venv/bin/python scripts/unified_workbook_control.py \
  --input TCaR_joint_edited.xlsx \
  --output TCaR_joint_recomputed.xlsx \
  --scratch tmp/ncc_joint_workbook/new_run
```

입력 원본과 이미 존재하는 출력은 덮어쓰지 않는다. 실행 폴더는 비어 있어야 한다. 두 입력을 먼저 검증하고, 계산 중 입력 파일이 바뀌면 결과를 배포하지 않는다. 기존 시트에 결과와 실행 기록을 갱신하며 시트 순서·원문 입력·서식을 유지한다. 추가 시트의 셀도 보존 여부를 검사한다. 다만 임의의 피벗·외부 링크·매크로를 지원하는 범용 Excel 편집기는 아니다. 네이티브 Excel 앱에서의 실행은 아직 검증하지 않았다.

기존 단일 모형 파일 `TCaR_joint_research_control_v2.xlsx`는 출처가 있는 NCC 공정 물량, IEA 중심 가격, 공동 가격 충격을 실제 비용 계산에 연결한다. 노란 입력을 편집하면 중심 가격 비용은 수식으로 바뀌고, 저장한 파일을 재계산하면 몬테카를로 분포와 위험 통계가 갱신된다. 기존 29시트 기업 후보 통제 파일과 별도인 **부분 비용 모듈**이다. 네 기업의 신규 전체 비용 최적화를 완료한 파일로 해석하지 않는다. 이전6시트 파일도 읽을 수 있고 재생성 시 추가 문헌 참조가 포함된다.

## 기존 단일 모형의 사용 흐름

1. `Control`의 노란 15개 입력을 바꾸고 파일을 저장한다. 시나리오, 충격 생성법, 기간, 생산량, 가격, 판매·연동 비중, 환산율, 할인율, α, 경로 수와 시드를 지정한다.
2. `Annual cost`에서 중심 가격과 전력·메탄 물량의 비용 연결을 확인한다. 현재 결과와 입력이 다르면 위험 요약은 `재계산 필요`로 표시한다.
3. 편집한 파일로 재계산을 요청한다. 아래 명령으로도 실행할 수 있다. 입력 파일을 보존하고 새 파일에 결과를 만든다.
4. 새 `Control`의 결과, `Cost paths`의 경로별 기준·전환 비용, `MC summary`의 실행 입력을 확인한다. 시나리오·기술 원표를 임의 변경하면 실행은 중단된다. 이를 새 출처와 함께 모형에 반영한 후 다시 생성해야 한다.

```bash
.venv/bin/python scripts/joint_workbook_control.py \
  --input TCaR_joint_edited.xlsx \
  --output TCaR_joint_recomputed.xlsx \
  --scratch tmp/ncc_joint_workbook/my_run
```

Python 계산 환경과 Codex의 번들 Node/Artifact Tool 런타임이 필요하다. 현재 경로는 이 작업 컴퓨터에 지정되어 있다. Excel 내부에서 몬테카를로가 자동 실행되는 매크로가 아니다. 입력 파일의 사용자 추가 시트·서식은 새 결과 파일에 복사하지 않으며 입력 원본은 보존한다. 한 실행당 다른 scratch 폴더를 사용하면 실행 기록도 보존된다.

## 시트와 계산 경계

| 시트 | 기능 |
|---|---|
| Control | 15개 편집 입력, 부분 비용 위험, 입력·결과 일치 여부 |
| Annual cost | 연간 중심 가격, 물량, 구매비·판매 크레딧, 할인 계산 |
| Scenario source | IEA 2025 3개 시나리오의 원유·일본 LNG, 2024–2050 원표/보간 구분 |
| Technology DB | Layritz 기준/전기화 전력 0.21/6.99 MWh, 공통 나프타 3.58 t, 내부 메탄 0.488 t; 모두 에틸렌 1 t당 |
| MC summary | 실행 입력과 출처 해시, 경로 데이터로 독립 계산한 평균·분위수·ES |
| Cost paths | 같은 경로의 기준 비용, 전환 비용, 그 차이와 ES 경계 초과분 |
| NCC reference | Tiggeloven 출판본39개 수치 행, 보충자료7종 부산물 수율·가격,5개 단위 변환 수식 및 채택 보류 이유 |

`NCC reference`는 검토용 자료다. 원문의% 표기와 유지비 정의, 플랜트 수명·개조비·메탄 및 증기 수지가 확정되기 전에는 현재 MC 입력으로 사용하지 않는다. 따라서 이 참조값을 수정해도 기존 Layritz 비용 분포는 바뀌지 않는다. 수정한 참조값이 새 파일에 원문 수치로 전파되는 것을 막기 위해, 재실행 시 출처 기록과 다른 참조 행은 거부한다. 새로운 가정을 적용하려면 해당 공정 사양과 비용 원장을 명시적으로 갱신해야 한다. 수율 변경 시 참조 변환 수식이 반응하는 것과 현재 MC가 다른 기술을 채택하는 것은 별개다.

전력·메탄 넷백·나프타의 2024년 가격, 통화 환산율, LNG 연동 비중, 메탄 판매 비중, 생산량은 명시적 가정이다. 원문 공정 물량의 확인과 실제 기업 조달가격 검증을 구별한다. IEA 원유는 수입 평균으로 나프타 가격 그 자체가 아니며, 일본 LNG는 기업 전력요금이나 메탄 판매가격이 아니다. 원표의 MMBtu 발열량 기준은 이 추출에서는 **미지정**이며 검증된 HHV로 표시하지 않는다.

나프타는 기준·전환 양쪽 총 부분 비용에 각각 포함된다. 동일 물량·가격이면 증분 비용에서 상쇄된다. 전기화로 남는 내부 메탄은 판매 가능한 비율만 넷백 크레딧으로 적용한다. 구매가스 회피비용으로도 중복 차감하지 않는다. 메탄 판매 넷백은 음수일 수 있다. 판매하지 않는 잔량에 비용·가치를 부여하지 않은 가정도 별도로 남는다.

이 모듈은 CAPEX·탄소·그 외 OPEX·제품 매출·생산량 조정·환율 충격을 제외한다. 가격 위험의 전파를 확인하기 위한 공정 참조 사례이며 총 기업 전환비용이나 새로운 기업 frontier 결과가 아니다. 기존 기업 후보 시스템의 450개 결과는 기존 입력·분포의 결과로 유지한다.

## 분포와 꼬리 통계

IEA 시나리오끼리 임의 확률로 섞지 않는다. 선택한 시나리오 안에서 과거 월별 벤치마크 가격 변화로 공동 충격을 만든다. 1·6·12·24개월 비순환 중첩 블록 재추출은 같은 월의 6개 가격을 함께 추출하며, 독립 월별 정규 모형은 추정한 공동 공분산을 쓴다. 블록 길이 12개월이 참인 미래 모형이라고 주장하지 않는다.

로그 변화의 과거 평균을 제거하고, 선언한 생성법에서 가격 배율의 이론적 기대값이 1이 되도록 지수 적률을 보정한다. 시뮬레이션한 표본의 평균으로 다시 나누지 않는다. 연중 구매량이 균등하다는 가정으로 12개월 가격을 산술 평균한다. 중심 가격은 장래 시나리오, 역사적 충격은 조건부 변동 구조다. 기업 계약의 잔차와 미래 정책 충격을 식별한 것으로 해석하지 않는다.

경로마다 전환 비용에서 같은 경로의 기준 비용을 빼고 할인한 뒤 분포를 계산한다. `TCaRα = Qα − Q0.5`이고, `ESα`는 상위 `1−α` 질량의 평균이다. Excel 분위수는 선형 보간 `PERCENTILE.INC`를 사용한다. ES는 `ceil(Nα)`번째 순서통계량을 경계로 초과분을 합산하여 경계 경로의 분할 가중을 반영한다. 따라서 `N(1−α)`가 정수가 아닌 경우에도 상위 경로를 단순 반올림해 평균하지 않는다.

## 확인한 동작

- 기본 10,000경로에서 Excel의 5개 통계가 FIN 결과와 일치한다. 최대 차이 2.19×10⁻¹¹ 십억 KRW2024, Excel 오류 셀 0개다.
- 실제 파일을 다시 읽어 NZE·LNG 연동 비중 0·101경로·α=0.95327로 실행한 뒤 새 파일의 꼬리 통계를 대조했다. 분할 꼬리 질량은 4.71973경로이며 최대 차이 5.46×10⁻¹² 십억 KRW2024다.
- 생산량 0은 모든 부분 비용 위험을 0으로 산출한다. 생산량 빈칸은 오류로 거부한다. 시나리오 원표·기술 물량 변경도 조용히 무시하지 않고 거부한다.
- 기본 평균 8,831.29, TCaR95 2,640.69, ES95 13,208.30은 **예시 가정의 십억 KRW2024 부분 비용**이다. 실제 회사의 관측 위험이 아니다.

검증은 Artifact Tool의 가져오기·편집·재계산·내보내기, XLSX 저장 셀의 독립 판독, 실제 FIN 재실행으로 수행했다. 네이티브 Microsoft Excel 앱에서의 실행 확인은 아직 수행하지 않았다. 101경로의 수정 실험은 연결과 ES 산식을 검증하는 검사이며 꼬리 추정 정밀도의 권장 경로 수가 아니다. 독립 시드·경로 수·모형 비교는 별도 장기 꼬리 감사 결과를 따른다.


## NCC 물량과 비용 연결의 선행 검사 (2026-09-08)

NCC cash 실행은 두 기술안의 같은 에틸렌 인도량·초기/말기 재고·생산 상한을 먼저 검사하고, 나프타 수율과 전력·메탄의 비용 물량을 대조한다. 불일치하면 NCC 가격 생성과 비용 평가를 중단한다. 실행 기록의 `delivery_contract`에 비교 조건과 검사 오차·구현 해시를 남긴다. 기존 Control 모형은 별도 계산 경로다. 이 검사는 실제 회사 수요나 감축 달성 가능성을 확인하는 것은 아니다. 새 입력 시트는 필요 없으며 기존 통합 v4 파일을 계속 사용할 수 있다.
