## 각 회차 규칙

1. 이 파일에서 첫 TODO 회차를 찾아 그것만 수행한다.
2. 웹 검색으로 1차 출처를 확보한다. 출처 없는 주장은 쓰지 않는다.
3. `docs/seminar/NN_*.md`에 기록 — 구조: **발견 / 투자자 함의 / 반론 / 출처**.
4. 상태표를 DONE으로 갱신하고, 발견한 것 중 다음 회차 초점을 바꿔야 할 게 있으면 계획을 고친다.
5. 커밋한다.
6. 사용자에게 3~5줄로 보고 — 무엇을 알아냈고, 세미나 논지가 어디로 기우는지.

## 누적 논지 후보 (회차마다 갱신)

**T1 (1회차, 잠정 유력).** *"라벨은 생겼는데 판정 기준이 없다."*
2025-11 ICMA CTBG·LMA TLP로 전환금융이 독립 상품군이 됐고, SFDR 2.0 'Transition' 범주가
2027년 실무 요건으로 도착한다. 그런데 무엇이 신뢰할 만한 전환계획인지 판정하는 방법론은
표준화돼 있지 않다(CTFH 2025 부속서는 도구 *목록*만 제시). 일본 GX 국채가 그 공백의 증거 —
ICMA 정합 프레임워크에 재생에너지 직접투자 0, CBI 인증 미갱신, greenium 대신 illiquidity discount.
→ 세미나가 팔 것: **투자자가 직접 전환계획을 심문하는 방법.** cap_finance가 그 도구인지는 6회차 판정.

**T2 (약함).** "전환금융의 시대" 프레임은 숫자가 안 받쳐줌 — 전환채 400억 달러는 라벨채 9,000억의 4.4%. 쓰지 말 것.

**버릴 것.** "라벨은 배출을 보증하지 않는다"만 말하면 진부. 차별화는 대안 판정법에 있음.
