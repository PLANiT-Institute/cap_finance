# 신규 석유화학 설비 현금 원장 사용법

최신 통합 파일은 `TCaR_joint_research_control_v4.xlsx`다. 두 모형의 통합 재계산은 [공동 가격 통제 사용법](JOINT_RESEARCH_CONTROL_KO.md)의 첫 명령을 따른다. `NCC cash`에서 노란 입력을 수정하고 저장한 파일로 재계산을 요청하면 새 결과 파일을 만든다. 현재 결과의 가정은 같은 시트 오른쪽에 기록한다. 입력이나 원문 수치·단위를 바꾸면 결과가 ‘재계산 필요’로 표시된다. 편집만으로 새 MC가 실행되는 매크로 파일은 아니다.

## 두 공정 모형의 구분

| 항목 | Control | NCC cash |
|---|---|---|
| 문헌 | Layritz 참조 | Tiggeloven 참조와 명시적 추가 가정 |
| 비용 범위 | 원료·전력·메탄 부분 비용 | 원료·전력·메탄·신규 설비·교체·유지비 |
| 비용 단위 | 십억 KRW2024 가정 | 백만 EUR2019 가정 |
| 생산 | 직접 입력하는 고정 연간 물량 | 원문 115t/h × 가동시간 |
| 계산 기간 | 2024–2050 범위에서 선택 | 투자2027–2029, 가동2030–2050 |
| 입력 | 기존15개 | 추가18개 |

각 모형의 입력과 계산 경계는 독립적이며 통합 갱신에서 두 실행을 함께 수행한다. 동일한 원문·시나리오 시트를 참조하더라도 물량·통화연도·비용 범위를 섞어 순위를 만들지 않는다. `NCC reference`의 채택 보류는 기본 Control에 자동 적용하지 않았다는 뜻이다. 신규 현금 모형은 수명·유지비·유효 증기 가정을 사용자가 명시하여 별도로 평가한다.

## 무엇을 바꿀 수 있는가

`NCC cash!B12:B29`에서 IEA시나리오, 공동 블록 길이, 시드, 경로 수, α, 증기 이용률, 연간 가동시간, 기존 방식·전기화 설비 수명, 유지비 표기 해석, 유지비 연간 환산 연율, 현금 할인율, 잔존가치, 전력·메탄·나프타 가격, 전력의 LNG 연동비중, 메탄 판매비율을 바꾼다. 나열된 항목은18개 입력이다. 같은 공정 모형의 비교이므로 양쪽 생산량을 동일하게 둔다. 가동시간은0보다 커야 한다. 생산을 중단해도 자본이 남는 별도 폐쇄 의사결정은 이 모형에 없다.

유지비 해석1은 기존 플랜트0.04·전기화0.02·보일러0.04를 소수 비율로 사용한다. 0.01은 표의%를 문자 그대로 해석하여 각각100분의1로 적용한다. 원문 해석이 확정됐다는 뜻이 아니다. 유지비는 연간 환산 투자비에 비율을 곱하며 투자비 자체는 지급·교체 일정으로 따로 처리한다. `none`은 잔존수입0, `straight_line_proxy`는 남은 수명의 직선 대용치이며 관측 처분가격이 아니다.

메탄 가격은 구매와 판매에 같은 값을 적용하는 단순화다. 미판매 메탄은 경계 밖 무상 이전으로 처리한다. 미판매를 배출0으로 인정하거나 실제 처리비를 검증한 것은 아니다. 판매·운송 비용과 구매가격의 차이는 후속 기업 조달 사양에서 분리해야 한다.

## 결과를 읽는 순서

1. `NCC cash`의 ‘최신 계산’을 확인하고 왼쪽 편집 값과 오른쪽 실행 값을 대조한다.
2. 평균·중앙값·상위 분위 비용·TCaR·ES를 함께 읽는다. TCaR는 qα−중앙값이다. 확정 비용이 변해도 TCaR는 그대로일 수 있다.
3. `NCC annual`에서 각 공정의24년 물량·투자비·잔존수입·유지비·중심 가격을 확인한다. 전력·원료·메탄 순비용과 할인합계는 Excel 수식이다.
4. `NCC paths`에서 같은 공동 가격 경로에 대한 두 공정 비용과 차이를 확인한다. ES는 정확한 꼬리 질량을 사용하며 마지막 경계 관측을 분할한다.

가격 중심 경로는 IEA의2024년 대비 비율이다. 전력·메탄·나프타의 기준 가격을 EUR2019 실질가격이라고 가정한 뒤 비율과 충격을 곱한다. 월별 과거6개 가격의 공동 변화에서 같은 블록을 뽑고 양수 가격의 이론적 기대배율을1로 보정한다. 12개월 산술 평균을 연간 구매가격으로 사용한다. 시나리오 발생확률을 추정하거나 과거에 없던 위기를 완전히 포착한 분포가 아니다.

## 검증 범위

기본5,000경로와 가정 변경101경로, 상품가격0의101경로를 실제 편집·저장·판독·FIN 실행·새 파일 생성으로 대조했다. 각 파일의5개 통계와48개 연간 현금식이 독립 계산과 일치했다. 101경로는 연결·분할 꼬리 수식 검사용이며 장기 위험 분석의 권장 표본 수가 아니다. 원문 변경과 잘못된 입력6종을 거부했다. 기존7시트의 값과 수식은 보존했다. Artifact Tool과 저장 XLSX를 검사했으며 네이티브 Microsoft Excel 앱 실행은 확인하지 않았다.

원문의 증기 압력별 공학적 타당성, 기존 회사 설비 개조비·잔여수명, 탄소비·노무비·운전자본·조세·금융비용·기타 부산물 순판매액은 미확정 또는 제외 상태다. 같은 생산·배출 제약을 맞춘 기업 후보의 효율경계로 자동 해석하지 않는다.

개발 환경에서는 `scripts/unified_workbook_control.py`에 입력 파일·별도 출력 파일·비어 있는 실행 저장 폴더를 주어 두 모형을 재계산한다. 기존 `scripts/ncc_cash_workbook_control.py`는 NCC cash만 갱신하는 단일 모형 경로다. 원본은 덮어쓰지 않는다. 연구 입력을 수정한 파일을 전달하면 같은 절차를 실행할 수 있다.


## NCC 물량과 비용 연결의 선행 검사 (2026-09-08)

NCC cash 실행은 두 기술안의 같은 에틸렌 인도량·초기/말기 재고·생산 상한을 먼저 검사하고, 나프타 수율과 전력·메탄의 비용 물량을 대조한다. 불일치하면 NCC 가격 생성과 비용 평가를 중단한다. 실행 기록의 `delivery_contract`에 비교 조건과 검사 오차·구현 해시를 남긴다. 기존 Control 모형은 별도 계산 경로다. 이 검사는 실제 회사 수요나 감축 달성 가능성을 확인하는 것은 아니다. 새 입력 시트는 필요 없으며 기존 통합 v4 파일을 계속 사용할 수 있다.
