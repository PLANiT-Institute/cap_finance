# 전환 투자 지연의 원천 — 문헌 지도와 CAP 표현 가능성 (2026-09-12)

질문: 기업(철강·석화)의 탈탄소 투자를 지연시키는 원천은 무엇이고, CAP의 분포 생성기("일정 고정 →
가격 경로 1만 개")는 그중 무엇을 표현할 수 있는가. 전 서지 웹 확인, 미확인은 표시.
코드 근거: `src/cap/e2_milp.py` — 일정은 회사별 중심 가격경로로 MILP 1회 확정, `tech_availability.csv`
가용연도는 시나리오별 결정론, 1만 경로는 고정 일정 위 사후 비용 재계산.

## 판정

1. **구조적 공백.** "일정 고정 → 가격 흔듦"은 문헌의 핵심 서사 — 불확실해서 기다린다(1·5·6) — 를
   원리적으로 못 담는다. 파라미터가 아니라 "일정 결정"과 "분포 생성"을 분리한 설계의 한계.
   우리가 흔드는 에너지 가격은 6원천 어디에도 없다 (R1: 전환에 대한 불확실성이 아니라 전환이 옮겨
   놓는 노출).
2. **최대 공백 = 원천 6.** 관측되는 실물 지연의 최대 몫이면서 모형 표현 불가 + 학술 실증 희박.
3. **원천 3은 이미 안에 있다.** 가장 적은 구조 변경으로 가장 큰 설명력 — 방어 가능한 프레임은
   "재투자 창이 고정한 시점 위에서의 비용 분포".

## 설계 함의 (2026-09-12 논의)

2층 구조(시나리오 s → 일정 z(s) → 가격 산포)로 가면 원천 1은 KAIST 시나리오 복수 + 시나리오
가중치로 들어오고 2·4·5는 시나리오 파라미터로 흡수 가능하다. 원천 6은 2층으로도 안 들어온다 —
수요·마진 확률화는 세 번째 축이며 별도 연구. 따라서 방향 문장: **"재투자 창이 고정한 시점 위에서,
정책 시나리오와 에너지 가격이 만드는 전환비용 분포"** — 수요·마진 대기는 명시적으로 범위 밖.
