# L8 — 8루프 종합 판정: 전환비용 분포와 세 주체 헤지 (2026-09-13)

여덟 루프를 착지시킨다. 새 문헌 없이, 모은 것을 "CAP 모형 설계·한·일 케이스·다음 작업"으로 번역.
근거는 각 루프 문서(같은 폴더 L1~L7, 서지 포함). 지난 9루프(../2026-09-13-hedging/)와 합류한다.

## 0. 한 문장
> 전환비용은 두 꼬리(상방=비용 폭발, 하방=좌초)를 가진 하나의 분포다. 기업·투자자·정부가 그 분포의
> 서로 다른 층을 지고, 한국은 꼬리 두 층이 비어 있다. TCaR는 그 분포에 expected shortfall을 적용해
> 층 크기를 재는 이름(Climate VaR 계보)이지 새 측도가 아니다.

## 1. 확정된 프레임
1. **대상 = 하나의 전환비용 분포 C(x)** — 위험 종류로 쪼개기 전, 총비용의 분포. MILP 일정 전체를
   1만 경로로 분포화(선례 없음 = CAP 자리, MACC 비판이 존재 근거).
2. **두 꼬리, 다른 원천** — 상방(CAPEX·에너지=짓는 돈, 멱함수 팻테일)·하방(탄소·정책=버는 돈, 좌초).
   ArcelorMittal €13억 포기·취소가 하방 실증 앵커.
3. **섹터가 분포 모양으로 갈림** — 철강 양쪽 꼬리(상방 그린필드 FOAK·하방 이산 좌초), 석화 얇은
   상방+연속 하방 몸통. 분포 모양이 헤지를 정함.
4. **세 주체가 층을 나눠 짐** — 기업 first-loss(retention)·투자자 mezzanine(insurance)·정부
   catastrophe(reinsurance). blended finance·보험 layering의 기존 언어.
5. **TCaR 안착** — ES를 전환비용 분포에 적용, Climate VaR(Dietz 2016) 계보 막내. 상방 TCaR·하방
   TCaR 두 꼬리 분해가 유일하고 과장 없는 기여. 새 측도 아님.
6. **얹혀가기 스택 8줄** — 분포 대상·위험측도·분포 모양·헤지 이유·헤지 비율·위험 배분·정부 한계·
   최근접 선행 전부 기존 틀. CAP은 한·일 케이스에 수치를 채움.

## 2. 8루프·9루프 합류 (한 논문의 두 반쪽)
- **9루프**(../2026-09-13-hedging/): "위험이 어떻게 생겼나" — 가격형/접근형/제도형, 조기 전환은
  접근형만 헤지, 철강 성립·석화 붕괴.
- **8루프**(이 폴더): "분포를 누가 어떻게 좁히나" — 두 꼬리·세 주체·layering·TCaR.
- **합류점**: 둘 다 v(S) = ES(C) − ES(T_S(C))로 만난다(L7). 같은 대상(전환비용 분포)의 양면:
  9루프는 분포를 **미는** 힘(위험 종류), 8루프는 분포를 **좁히는** 수단(헤지 층). 한 논문:
  "한·일 철강·석화의 전환비용 분포 — 무엇이 밀고(9루프), 누가 좁히나(8루프)."
- 조기 전환(9루프)은 접근형 위험을 선점으로 헤지 = 분포를 **왼쪽으로 미는** 것. 계약·CCfD(8루프)는
  꼬리를 **자르는** 것. 둘이 한 (기대비용, TCaR) 평면에서 만난다.

## 3. CAP 모형 설계 (계산 엔진)
```
MILP 일정 생성 (시설 단위, 재투자 창)
  → MC 1만 가격경로 (검증 계열, 두 꼬리: 상방 CAPEX·에너지 / 하방 탄소·정책)
  → 전환비용 분포 C(x)
  → 층 경계 (분위수): 몸통 / 상방 꼬리 / 하방 꼬리
  → TCaR (상방 ES_α(C) 원화 / 하방 ES_α(−순가치) 원화)
  → 수단별 v(S) 페이오프 변환 (하방절단=CCfD·하한 / 상방캡=EPC·보증 / 칼라=CCfD·GX밴드)
  → 세 주체 배분 (기업 보유·투자자 mezzanine·정부 catastrophe, 미가동=빈 tranche)
검증: 소거실험(수단 끄기, v(S) 직접) + λ 스윕(효율 프론티어) + T1~T3(요금·GBM/OU·시설 π)
```
분포 함정(GBM 24년 복리 등)은 **수준**에 영향, **방향·순위·층 크기 비교**는 견고. 수준 절대값 주장 금지.

## 4. 한·일 케이스로 무엇을 파나
- **한국 = 전환비용 분포 꼬리가 무주공산.** 기업 corporate 그린본드로 몸통 통째, 정부 무상할당·
  790조로 몸통만, 상방 진입부(②)·하방 좌초(③) 두 tranche가 빈다. CCfD 미가동(법제화 착수).
- **일본 = 양쪽 꼬리(GX-ETS 밴드) + 몸통(GX 국채) 다 다룸.** 정부가 발행자로 탄소 붕괴 위험 내재화.
- **유럽 = ECA가 mezzanine까지 두껍게 + CCfD(KSV) 가동.**
- **발견**: 같은 전환비용 분포인데 세 나라가 층을 나누는 방식이 다르고, 한국만 꼬리가 비었다. Wolf
  2025(유럽 2주체)가 못 보는 것. **논문의 그림 한 장 = 세 나라 위험 배분 지도.**
- POSCO·NSC는 프로젝트 계층화 없이 기업 신용에 통째로 진다(서구 그린스틸 project finance와 대조).

## 5. 정직한 형태 (감사·L5·L6·L7 일관)
CAP은 **측정 도구이지 처방 도구 아님.** 층을 그리고 각 층 크기를 원화로 재되, 누가 채워야 하는지는
안 말함. "정부가 하방을 잘라야 한다"고 처방 안 함 — "이 꼬리는 민간이 못 지고, 정부가 지면 자기
위험 재보험(Kydland-Prescott)이라 신뢰성 장치 없이 넘기면 재정으로 재귀한다"는 조건부 기술. Arrow-Lind
안 걸림. π는 위험 이전 회계이지 사회적 가치 아님.

## 6. 데이터·다음 작업
- **엑셀화 추가 열**(8루프): 각 주체의 실제 참여(기업 그린본드·investor PF·정부 CCfD/보증), 계약
  단계(MOU/구속력), CBAM 수출 노출, 한·일 제도 수단 가동 여부.
- **코드**: 층 경계 분위수 산출, TCaR 상방/하방 분리, 수단별 v(S) 변환(하방절단·상방캡·칼라),
  세 주체 배분 표. 지난 9루프 DIRECTION의 v(S) 구현과 공유.
- **테스트**: 소거실험 + λ 스윕 + T1~T3.
- **미확인 서지 A순위**: Flyvbjerg 참조집단(전환설비 배정), Wolf 2025 정량, Krokhmal 2002, ArcelorMittal
  취소 1차, 한국 CCfD 시행세칙, ECA EPC 초과 직접커버 — 기관접속 다음 사이클.

## 7. TCaR 생존 판정
**산다 — 스타가 아니라 도구로.** "새 측도 TCaR"로는 죽고(왜 새 이름?), "ES를 전환비용 분포에 적용한
Climate VaR 계보의 이름 + 두 꼬리 분해"로는 산다. novelty가 얇은 건 사실 — 그래서 무게를 측도가
아니라 **케이스**(한·일 층 크기·꼬리 공백)에 싣는다. 논문 주인공은 "한·일 전환비용 분포의 층 크기와
빈 tranche", TCaR는 그걸 재는 자. 수준 아닌 순위·방향·비교만 주장하면 분포 함정도 피한다.
