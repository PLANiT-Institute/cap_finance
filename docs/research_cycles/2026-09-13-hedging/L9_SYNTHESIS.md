# L9 — 9루프 종합 판정: 산업 특성 헤지와 전환 관점의 불확실성 (2026-09-13)

여덟 루프(L1~L8)를 착지시킨다. 새 문헌 없이, 모은 것을 "분포를 어떻게 흔들고, 무엇을 코드로 바꾸고,
무엇을 데이터로 모으나"로 번역한다. 근거는 각 루프 문서(같은 폴더 L1~L8, 서지 포함).

## 0. 아홉 루프를 관통한 한 문장
> 전환은 위험을 없애지 않고 **종류를 바꾼다** — 가격형에서 접근형·제도형으로. 조기 전환은 그중
> **접근형만**, 그것도 자원이 진짜 희소하고 전환이 배출을 진짜 없앨 때만 헤지한다. **철강에선 성립**
> (수출·CBAM·감축 가능), **석화에선 깨진다**(embedded 배출·flexi-cracker). 이 대조가 논문이다.

사용자 원 직관("에너지 불확실성을 전환이 헤지")은 틀리지 않았고, 아홉 루프가 그것을 정밀·반증가능
형태로 깎았다.

## 1. 확정된 척추
1. **위험 세 종류** — 가격형(계약으로 산다) / 접근형(선점으로 확보) / 제도형(정부가 만들거나 없앰).
2. **수단 삼분 대응** — 시장·계약 / 조기 전환(선점) / 정부 커미트먼트(CCfD 스왑·하한 풋·밴드 칼라).
3. **조기 전환은 접근형만 헤지** — 가격형은 전환 안 해도 계약으로, 제도형은 정부만.
4. **접근형 = carbon lock-in의 금융적 표현** — 만료일(재투자 창 62기·2026-35), 메커니즘(선점).
5. **6조건** — 자원 희소성·경쟁 강도·커미트먼트 신뢰성·기술 성숙·보완 역량·자기정당화 배제. 조기
   전환은 이게 성립할 때만 헤지(escalation of commitment 가드) → 옹호가 아니라 반증가능 주장.
6. **철강·석화 비대칭** — 철강=실증(CBAM·감축가능·기존헤지 없음), 석화=경계(CBAM 미적용·감축상한
   30%·flexi-cracker 기존헤지). 4사 2-2(POSCO·NSC / LOTTE·MCI).
7. **이론** — 헤지 계보(Miao-Wang) × 선점 계보(Grenadier)를 상태축×시간축 직교 분해로 결합. CAP
   novelty이자 검증 부담(자기 데이터로 입증 + 소거실험 + λ 비교정학).

## 2. 분포를 흔드는 최종 설계
위험을 종류별로 다른 수학적 대상으로 — 이것이 9루프의 핵심 설계 결론이다. "세 축을 다 GBM으로
흔든다"가 아니다.

| 노출 | 종류 | 수학적 대상 | 근거 루프 |
|---|---|---|---|
| 전력(계통 잔여 β) | 가격형 | 연간 로그 충격 σ_grid (SMP-LNG) | L1 |
| 전력(재생 PPA α·(1−α)) | 가격형(낮은 σ) | σ_PPA≈정책, 100% 고정 아님(지수+고정 혼합) | L1 |
| 원료탄·나프타 | 가격형 | 연간 σ, 전환 시 소멸 노드 | L2 |
| 스크랩 가격 | 가격형 | σ (LME 선물 존재) | L6 |
| **DR펠릿·스크랩품질·수소물량·재생PPA물량** | **접근형** | **시간의존 페널티 f(t)=배급실패확률(t)·단가승수(t), 결정론** | L2·L3·L5 |
| CBAM 시장접근 | 접근형(제도형 번역) | 무전환 계획에 시장접근 상실 페널티(수출 노출 비례) | L4 |
| 탄소 수준 | 제도형 | 시나리오 층(확률 없이 조건부·robust 밴드) + KAU 변동 σ | L4 |
| CCfD 창구·할당 규칙 | 제도형 | 정책 존재 확률(기업 미헤지) | L3·L4 |
| 감축기술 학습 | (폐기) | 학습 약·CAPEX 반등 → 하락 시나리오 폐기, 결정론 상수 유지 | L3 |
| 전해조 CAPEX | 가격형 | 양방향 σ(반등 실현치), 결정론 아님 | L3 |
| 석화 embedded 배출 | 구조적 상한 | 감축 페이오프에 30% 캡 | L2·L6 |

**직교 분해(L7)**: (a) 헤지 효과 = **상태 함수**(무전환 반사실 꼬리 상태에서 조기 전환 노출 감소,
시나리오 설계 + 종가 처리 필수), (b) 선점 효과 = **시간 함수**(f(t), MILP 결정론 계수). 상태 vs
시간이라 이중계상 없음 — 소거실험(a→0 무전환 확률 0, b→0 무제한 계통)으로 분해 보고.

**철강·석화 비대칭 반영**: CBAM 연결계수 철강 높음·석화 ≈0. 석화 감축 30% 캡. 접근형 내부 차등
(재생PPA·DR펠릿 강 / 수소 약 — 철강 후순위). flexi-cracker 옵션가치를 석화 두 기준선에 내재.

## 3. 조기 전환 결론의 정직한 형태
"조기 전환은 좋다"(옹호) ❌. **"조기 전환은 다음이 성립할 때 위험효율적이다"**(조건부·반증가능) ✅:
- 접근형 위험이 지배적이고(가격형은 계약으로 헤지되므로 조기 전환 불요),
- 자원이 진짜 희소하며 기업이 선점 경쟁에서 이길 위치이고(6조건),
- 전환이 배출을 실제로 없애고(철강 yes·석화 no),
- 탄소 강화 확률이 높다(완화되면 좌초 — 비대칭, 문헌 공백=기여).
철강(수출·CBAM·감축가능·수소 외 자원 선점 가능)에서 성립, 석화(embedded·flexi-cracker·CBAM 미적용)
에서 붕괴. **대조가 발견.**

## 4. 코드 변경 범위 (L2~L7 통합, DIRECTION 위)
- 전력: `re_price` 되살려 α·(1−α)·β 3분해(L1). β를 접근형 f(t)에 연결.
- 접근형 f(t): 시간의존 페널티를 MILP 계수·plancost에. DR펠릿·수소·재생PPA 물량별(L2·L3·L5).
- CBAM: 무전환 계획에 시장접근 상실 페널티, 철강만(L4·L6).
- 탄소: 시나리오 확률/robust 밴드 + KAU σ 재정의(이중계상 제거)(L4).
- 수소: 학습 시나리오 폐기, 전해조 σ 양방향, 물량·정책 존재 축 추가(L3).
- 석화: 감축 30% 캡, flexi-cracker 기준선 내재, CBAM 계수 ≈0(L6).
- 종가 처리(2050 절단) — 헤지 상태축의 전제(L7).
- 소거실험 2개(a축·b축) 강건성 표(L7).
- λ 비교정학 스윕(위험회피↑→조기전환)(L7).

## 5. 데이터(엑셀화)·테스트 순서
**엑셀화 열 규격** (모든 값에): `value / unit / source_id / retrieved_at / quality_tier / 추정값격리`.
추가 필수 열(9루프 결과): **계약 단계**(MOU/타당성/구속력 오프테이크 — 조기 전환 헤지 가치의 실측,
L6), **접근형 자원 선점 여부**(DR펠릿·재생PPA·수소 장기계약 확보), **CBAM 수출 노출**(대EU 물량).
기업당 시트 1개, 시설·연도 패널 + 재무 + 공시 계획 + 접근형 확보 현황.

**테스트 순서**: T2(한전 요금 σ_E 재보정) → T1(GBM vs OU 순위 불변) → T3(시설별 π 분산) →
소거실험(헤지축·선점축 분해) → λ 스윕. 앞의 셋은 DIRECTION 기존, 뒤 둘은 9루프 신규.
