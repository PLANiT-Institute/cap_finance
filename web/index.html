Capital Allocation Pathway

철강·석유화학 기업의 탈탄소 전환을 얼마가 드는가가 아니라 무엇에 얼마나 흔들리는가로 측정한다. 시설 단위 최적화로 기업이 선택할 수 있는 계획 전체를 생성하고, 가격 변동 경로 수만 개에 통과시켜 기대비용과 TCaR(P90−P50)의 효율 경계를 그린다. 공시 계획이 그 경계에서 얼마나 떨어져 있는지가 진단 결과다.

데이터와 재현

git clone https://github.com/PLANiT-Institute/cap_finance
cd cap_finance && python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/python scripts/prepare_raw.py     # 원자료 → 정규화 (가정 전수 로그)
.venv/bin/python -m cap all --data data/prepared
  • 시설·기업 연결: data/crosswalk_facilities.csv — 두 모형의 설비 ID 매핑(양 저장소 동일 사본)
  • 가정 감사 추적: data/prepared/PREP_LOG.md — 주입·추정·환산 전건 기록
  • 증거 성숙도: EFF data/data_gap_registry.csv — 입력별 P0/P1 보강 우선순위
읽기 전 필수. 수집 데이터의 상당 부분이 잠정 추정(EST_v0)이고 섹터 예산·가격 경로는 공식 GCAM 추출 대기 상태다. 절대값은 구간, 구조·순서가 유효 정보다. 시설 단위 산출은 지역·고용 문제와 직결되므로 비공개 원칙(설계서 §8-2)을 따르며, 공개 배포본에서는 기업 집계만 인용할 것.
